## Featured Projects

### GroundingPI

**A Grounding Foundation Model towards Physical Intelligence with Visual Primitives**

GroundingPI is a 4B grounding foundation model that generates points and boxes as quantized coordinates in a shared vocabulary, setting a new state of the art across 34 grounding benchmarks and serving as a perceptual backbone for robot manipulation and autonomous driving.

[Project website](https://groundingpi.github.io/) · [Paper](https://arxiv.org/abs/2609.39601) · [Code](https://github.com/groundingpi/GroundingPI) · [Model](https://huggingface.co/GroundingPI/GroundingPI)

### GroundAnything

**Reconciling Parallel Decoding with Precise Visual Grounding at Flash Speed**

GroundAnything combines parallel decoding with precise visual grounding for flash-speed inference, available in both diffusion (DLM) and autoregressive (VLM) variants.

[Project website](https://groundingpi.github.io/groundanything/) · [Paper](https://arxiv.org/abs/2609.39600) · [Code](https://github.com/groundingpi/GroundAnything) · [Model](https://huggingface.co/GroundingPI/GroundAnything-VLM)

### X-AuT

**Progressive Audio-Encoder Compression for Speech LLMs with Cross-Scale Distillation**

X-AuT explores efficient audio encoders for speech-language models through progressive compression and cross-scale knowledge transfer.

[Project website](https://xpeng-ai.github.io/x-aut/) · [Paper](https://arxiv.org/abs/2609.11412) · [Code](https://github.com/XPENG-AI/X-AuT) · [Model](https://huggingface.co/XPENG-AI/X-AuT)

### OmniGUI

**Benchmarking GUI Agents in Omni-Modal Smartphone Environments**

OmniGUI is a step-level benchmark for evaluating GUI agents with interleaved screenshots, audio, video, and action history in smartphone environments.

[Project website](https://omni-gui.github.io/) · [Paper](https://arxiv.org/abs/2605.18758) · [Code](https://github.com/omni-gui/OmniGUI) · [Dataset](https://huggingface.co/datasets/OmniGUI/OmniGUI)
